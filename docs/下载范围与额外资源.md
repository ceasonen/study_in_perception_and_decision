# 下载范围与额外资源

## 已收集与未包含的内容

本库下载各项目公开默认分支的源码快照，保留其中的代码、配置、说明、许可与随仓库提供的示例资产。声明的 Git 子模块按上游返回的既有版本引用递归下载并展开。这是工作文件快照，不包括各项目的 Git 历史、所有分支和所有 release。

Tianshou 是用户提供的本地 `master` 源码，已移动到 `repositories/decision/D07_Tianshou/`；`pyproject.toml` 标记版本 2.0.1，最近提交日期为 2026-04-03。整合时未覆盖为在线最新源码。工作文件另存归档用于目录与文件大小检查；原 Git 元数据保留在本地忽略目录 `downloads/git_backups/D07_Tianshou.git`，不上传。来源与版本单独记入下载记录。

每篇选定论文下载完整 PDF，使用 `pdfinfo` 读取页数，并提取第一页核对题名。没有计算或验证文件哈希。下载档案、原始网页和提取的临时文本保存在本地 `downloads/`，不重复提交到 GitHub。

独立发布的数据集、完整模型权重、场景资源与安装后的 Python／CUDA 环境没有批量下载。它们的规模、访问方式和任务选择不同；下面列出进入训练前要准备的内容。源代码快照完整不代表训练输入已经齐备。

MALib 的 `.gitmodules` 中残留了 SMARTS 的旧路径声明，但上游完整文件树中没有该路径，也没有对应子模块条目。此声明作为 `stale_declaration` 留在下载记录中；没有下载无关的当前 SMARTS 版本来冒充原始依赖。

## 如何继续下载

```sh
# 需要 Python 3.11+、curl，以及 Poppler 的 pdfinfo / pdftotext。
# 已完成项目会跳过，未完成项目会重试；按清单逐项下载。
python3 scripts/download_resources.py

# 重新生成资源索引与学习卡。
python3 scripts/build_indexes.py
```

这些命令不会安装或执行第三方训练程序。默认分支可能随时间更新，快照的下载日期、分支和来源在 `resources/download_status.json` 中；子模块版本引用来自 GitHub，不做本地哈希计算或校验。

若后续要更新一个已经下载的项目，应另建快照目录并记录日期，避免直接覆盖正在做实验的代码。当前辅助程序面向初次收集与失败重试，不提供代码合并或环境迁移功能。
