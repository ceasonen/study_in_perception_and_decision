# 读论文：提升研究理解与判断

论文全文在 `papers/`，按感知、决策、闭环分类。题名、发表信息与本地 PDF 见[论文索引](论文索引.md)。同一篇论文只保存一份；框架论文、算法论文、平台论文的阅读目标不同。

## 阅读时要积累的能力

| 能力 | 读完后能回答什么 |
| --- | --- |
| 定义问题 | 研究对象、输入输出、约束和评价目标到底是什么？ |
| 理解假设 | 方法依赖哪些数据、可观测信息、环境规律或训练条件？ |
| 理解方法 | 相对可靠基线改了什么，为什么预期这种改变会有效？ |
| 评估证据 | 主结果支持多强的结论，消融和失败案例能排除哪些解释？ |
| 形成联系 | 与你已有的视觉、概率建模、控制和强化学习知识怎样连接？ |
| 提出问题 | 哪个限制值得进一步验证，现有平台是否适合检验它？ |

第一遍读摘要、引言、核心图与结论，用自己的话写清楚任务与主张。第二遍读方法，理清符号、模型和损失；遇到关键公式，至少追到它所依赖的概念，不要只记名字。第三遍看实验，检查比较条件、训练数据、计算预算、指标与失败模式。最后再连接到对应源码。

先读清楚“作者为什么这样设计”，再用程序核对“设计实际上怎么实现”。论文往往省略采样、初始化和运行细节，代码也可能是论文发表后的更新版本，二者需要对照。

## 感知组

| 资料 | 主要学习目标 | 建议读法 |
| --- | --- | --- |
| ResNet、ViT | 残差、注意力、骨干网络和视觉表示的基本结构 | 已熟悉者快速复习，检查自己能否解释计算流与训练目标 |
| DETR | 用集合预测重新表述检测任务 | 推导匹配与监督的关系；理解查询究竟承担什么角色 |
| DINOv2 | 不依赖下游标签的视觉表示如何获得 | 理清 teacher–student 与图像／patch 目标，观察迁移范围 |
| DINOv3 | 密集特征稳定性与规模变化 | 在 DINOv2 基础上读新增机制，避免只关注大模型成绩 |
| ByteTrack | 对低置信观测与轨迹连续性的利用 | 把检测错误和关联错误分开理解 |
| GlobalTrack | 长期目标丢失与全图实例重定位 | 对比局部跟踪假设；联系老师参与的视觉研究 |
| CSTrack | RGB-X 信息怎样在空间和时间上结合 | 理清每个模态提供的不同信息以及两阶段训练 |
| GroundingDINO | 语言条件怎样改变感知目标 | 区分开放词表定位、关系理解与物理可操作性 |

感知论文应留下一个明确认识：其指标测量了什么，哪些行动相关信息未被评价。判断其是否适合你的决策任务，需要比单独看视觉排行榜更具体的任务分析。

## 决策组

| 资料 | 主要学习目标 | 建议读法 |
| --- | --- | --- |
| PPO | 稳定策略更新的目标与近似 | 区分优化目标、优势估计与执行策略；理解 clip 的作用边界 |
| SAC | 最大熵目标与 off-policy 学习 | 推导价值目标，理解熵温度和双 Q 的作用 |
| CleanRL、Stable-Baselines3 | 实现工具如何支持可重复实验 | 简读框架论文，重点把其职责与 PPO／SAC 区分 |
| MAPPO | 多智能体集中训练分散执行 | 列出 actor／critic 的信息差异与实现条件 |
| QMIX | 联合价值的可分解结构 | 理解单调性带来的分散执行性质和表示限制 |
| TAPE | 协作关系怎样影响策略梯度 | 理清拓扑、coalition utility 与论文证明假设 |
| 分布式 RL 综述、M2RL、MALib | 算法、种群、自博弈与分布式系统如何分工 | 画出信息、任务和策略种群流程，避免把吞吐提升等同于样本效率 |
| 人机对抗智能技术 | 认知决策与博弈学习的研究问题地图 | 用于建立方向脉络，不把综述直接当作复现项目 |

决策论文应明确环境步数、训练更新数和实际耗时是否区分，执行时是否使用额外真实状态，以及合作任务、竞争任务与泛化对手的评价是否混在一起。

## 闭环组

| 资料 | 主要学习目标 | 建议读法 |
| --- | --- | --- |
| DrQ-v2 | 像素、视觉增强与策略学习怎样共同训练 | 首个重点闭环项目；把编码器和 actor–critic 的更新联系起来 |
| DreamerV3 | 潜在状态与想象轨迹怎样支持决策 | 分清表征、动力学、奖励和策略目标；比较模型误差的作用 |
| Habitat 1.0／2.0 | 传感器、任务、仿真和长时程交互如何设计 | 根据所选任务读，关注数据划分和信息获取方式 |
| ACT | 动作分块与示范学习的联系 | 理解训练目标与闭环动作执行之间的差异 |
| Diffusion Policy | 动作分布建模与滚动执行 | 关注多模态行为、时间尺度和控制延迟 |
| CoS | 细粒度过程奖励与视觉语言推理 | 区分奖励质量、答案正确与行动正确；核对公开训练阶段 |
| π₀、π₀.₅ | 视觉语言动作模型的适配与泛化 | 先明确平台与数据，再理解动作专家、flow matching 和泛化训练 |

## 读完一篇怎样留下自己的积累

建议用[论文笔记模板](templates/论文笔记.md)保留一至两页笔记。第一轮精读集中在 DETR、DINOv2、ByteTrack、PPO、SAC、DrQ-v2、DreamerV3、MAPPO。每读完一篇，应能不看原文解释它的关键设计，并指出至少一个尚未覆盖的适用条件。

不要求第一轮复现所有表格，也不把读懂全部数学证明作为开始接触代码的先决条件。对于证明中的关键假设，应准确记录；对于暂时不懂的部分，列成具体待查问题，再通过后续阅读补齐。

[代码阅读指南](代码阅读指南.md)单独讨论如何学习作者的实现方法；完整的阶段安排见[12 周路线](学习路线与选题判断.md)。
